# Retired v1 reference

These Python/Jekyll sources, locks, templates and tests are retained for historical inspection. They are unsupported reference material, excluded from production and CI. Their former root paths and all production callers are retired. Use only the root Node commands and v2 documentation for acquisition, rendering, publication and recovery.

The preserved v1 archive is a separate Git history on `mirror-data`, checkpointed as `v1-final-before-v2` during cutover. Nothing in this directory seeds or converts the fresh v2 archive. The reviewed editorial fixtures remain in root `tests/fixtures/production/` and are exercised by the Node tests.
