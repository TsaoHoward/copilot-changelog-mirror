### [Build and review together with Canvas in Teams](#archive-heading-2)

![Canvas for Teams](https://github.com/user-attachments/assets/8f45ee45-9734-4cfc-b4d3-6a35c9531d01)

Turn team discussions into working code. With **Canvas**, you can review implementation plans, code changes, and previews alongside your conversation. Continue the discussion with teammates, share feedback, and refine the implementation together—all without leaving Teams.

<a id="archive-heading-3"></a>

### [Additional improvements](#archive-heading-3)

-   **Faster onboarding:** Go from request to coding session with fewer steps. `@GitHub` now identifies the repository from your message and launches your session without requiring you to select it again. Getting started is also easier when you’re not signed in, don’t have a default repository, want to switch repositories, or need app access.
-   **More reliable conversations:** Fixed an issue that could prevent responses to follow-up messages, helping you keep work moving.
    
-   **Clearer attribution:** Issues and pull requests created by `@GitHub` now include “Created from a Slack/Teams conversation with @username” in their description.
