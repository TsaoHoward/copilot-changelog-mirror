Gemini 4 Neon is now generally available in GitHub Copilot. It is designed for agentic coding, multistep tool use, and knowledge work. According to Google, Gemini 4 Neon delivers quality close to Gemini 4 Carbon at a lower token cost per task. Google also reports that, compared with Gemini 4 Carbon, it starts responding faster and makes fewer unrequested changes on coding tasks. It is also less likely to make unsupported claims about code, tool, or test results.

This model is billed at provider list pricing under usage-based billing. See [Models and pricing for GitHub Copilot](https://docs.github.com/copilot/reference/copilot-billing/models-and-pricing) for details.

### [Availability in GitHub Copilot](#archive-heading-1)

Gemini 4 Neon is available to Copilot Pro+, Max, Business, and Enterprise users. You can select the model in the model picker in:

-   Visual Studio Code
-   Visual Studio
-   Copilot CLI
-   GitHub Copilot coding agent
-   GitHub Copilot app
-   github.com
-   GitHub Mobile on iOS and Android
-   JetBrains IDEs
-   Xcode
-   Eclipse

Rollout will be gradual. Check back soon if you don’t see it yet.

<a id="archive-heading-2"></a>

### [Enabling access](#archive-heading-2)

Copilot Enterprise and Copilot Business plan administrators can manage access to Gemini 4 Neon through the model policy in Copilot settings. Under default model enablement, new models are automatically enabled unless an administrator has turned off the global default or explicitly disables this model.
