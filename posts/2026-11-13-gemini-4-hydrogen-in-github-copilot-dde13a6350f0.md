Gemini 4 Hydrogen, Google’s latest Flash model, is now generally available in GitHub Copilot. It is designed for fast, efficient agentic coding, tool use, and multistep workflows, with improved instruction following over Gemini 3.8 Flash.

This model is billed at provider list pricing under usage-based billing. See [Models and pricing for GitHub Copilot](https://docs.github.com/copilot/reference/copilot-billing/models-and-pricing) for details.

<a id="archive-heading-1"></a>

### [Availability in GitHub Copilot](#archive-heading-1)

Gemini 4 Hydrogen is available to Copilot Pro, Pro+, Max, Business, and Enterprise users. You can select the model in the model picker in:

-   Visual Studio Code
-   Visual Studio
-   Copilot CLI
-   GitHub Copilot coding agent
-   GitHub Copilot app
-   github.com
-   GitHub Mobile on iOS and Android
-   JetBrains IDEs
-   Xcode
-   Eclipse
-   Copilot SDK

Rollout will be gradual. Check back soon if you don’t see it yet.

<a id="archive-heading-2"></a>

### [Enabling access](#archive-heading-2)

Copilot Enterprise and Copilot Business plan administrators can manage access to Gemini 4 Hydrogen through the model policy in Copilot settings. Under default model enablement, new models are automatically enabled unless an administrator has turned off the global default or explicitly disables this model.
