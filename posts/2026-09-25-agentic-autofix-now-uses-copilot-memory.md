Agentic autofix now uses Copilot Memory for customers who’ve enabled it. When you use agentic autofix, it reviews existing memories for context that can help resolve security alerts. When it creates a fix, it stores the fix pattern as a memory for future use.

These memories can help agentic autofix resolve additional security alerts and teach other GitHub Copilot features (e.g., Copilot code review, Copilot cloud agent) about secure development patterns unique to your repository.

Both agentic autofix and Copilot Memory are available in public preview.

Learn more in [our docs about GitHub Copilot Memory](https://docs.github.com/enterprise-cloud@latest/copilot/concepts/agents/copilot-memory).
