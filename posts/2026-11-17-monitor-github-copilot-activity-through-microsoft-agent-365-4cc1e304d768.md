Enterprises can now stream GitHub Copilot agent activity directly into  
[Microsoft Agent 365](https://learn.microsoft.com/microsoft-agent-365/overview). This lets you bring audit data from across GitHub Copilot clients into Microsoft’s agent control plane, where you can review Copilot activity alongside other AI workloads.

With this release, administrators can:

-   See activity across Copilot clients, including cloud agents on GitHub.com, Copilot CLI, Visual Studio Code, Visual Studio, and partner IDEs such as JetBrains and Eclipse.
-   Review user sessions, including prompts, responses, and tool calls, and view usage trends in Agent 365.
-   Access additional risk information in Microsoft Purview and Defender to investigate and mitigate risk.

This is available for GitHub Enterprise Cloud customers with Enterprise Managed Users. To get started, see [Streaming the audit log for your enterprise](https://docs.github.com/enterprise-cloud@latest/admin/monitoring-activity-in-your-enterprise/reviewing-audit-logs-for-your-enterprise/streaming-the-audit-log-for-your-enterprise?utm_source=agent-visibility-changelog-stream-audit-log-docs&utm_medium=changelog&utm_campaign=ignite-nov-2026) on GitHub Docs.
