Enterprises working with a GitHub or Microsoft account team can now get Copilot included with GitHub Enterprise for every licensed user. Previously, you had to manage two things: how many Copilot seats you were paying for and how much AI usage those users consumed. With Copilot included in the platform, usage against your enterprise budget is the primary thing to manage.

Self-serve availability is coming in stages, and current self-serve subscriptions are unaffected. Copilot Business and Copilot Enterprise remain available.

Users in your enterprise account who do not hold a GitHub Enterprise license get the same Copilot access through Copilot Standalone, at $10 per user per month.

Copilot access through GitHub Enterprise and Copilot Standalone has the same features and models as Copilot Enterprise but does not include monthly AI credits per seat.

## [What you manage](#archive-heading-1)

AI usage is metered from the first request against your enterprise budget, using the policies, alerts, and attribution you already have. There is no included usage allowance to track or top up. To learn more, review our documentation on [Copilot billing for enterprises](https://docs.github.com/copilot/concepts/billing-and-usage/organizations-and-enterprises/billing?utm_source=ghec-changelog-billing-docs&utm_medium=changelog&utm_campaign=universe-2026).

-   Code completion and next edit suggestions keep working even with no budget available.
-   Copilot Chat, Copilot code review, and Copilot in the cloud require available budget to use.
-   An exhausted budget never removes access. The seat and the features that don’t need budget stay.

## [Availability](#archive-heading-2)

-   **If you work with a GitHub or Microsoft account team:** Available now for GitHub Enterprise Cloud. Talk to your sales team about setting up a new enterprise account on this model or transitioning an existing enterprise account.
-   **If you manage your own subscription:** Currently unavailable. We are opening this to self-serve customers in stages and will share dates in the coming weeks. Your current subscription is unaffected.
-   **Copilot Business and Copilot Enterprise:** Both remain available to purchase for new and existing enterprises.

To learn more, check out our updated documentation on [Copilot access](https://docs.github.com/copilot/get-started/whats-changing-with-github-enterprise-and-copilot?utm_source=ghec-changelog-enterprise-access-docs&utm_medium=changelog&utm_campaign=universe-2026).
