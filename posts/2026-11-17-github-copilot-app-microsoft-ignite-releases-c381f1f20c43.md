Copilot is most useful when it can work where you do. The GitHub Copilot app now supports your Azure DevOps repositories, your GitHub Enterprise Server instance, and the browser you’re already signed in to.

<a id="archive-heading-1"></a>

### [Work with Azure DevOps repositories in the GitHub Copilot app](#archive-heading-1)

Clone an Azure DevOps repository, ask an agent to create a branch, make code changes, and open a pull request, then see it through to completion without leaving the GitHub Copilot app. Track its status in the sidebar, click **Fix** on a review comment to have an agent address it, or turn on agent merge to let an agent fix CI failures and complete the pull request once your Azure DevOps checks and policies pass.

Azure DevOps integration is now in public preview. To get started, open **Settings** > **Experimental** and turn on **Azure DevOps integration**, then go to **Accounts** > **Add account** and sign in with the Microsoft account you use for Azure DevOps. Cloud sessions aren’t available for Azure DevOps repositories.

For more information, see the [Azure DevOps documentation](https://docs.github.com/copilot/how-tos/github-copilot-app/manage-azure-devops-work?utm_source=app-changelog-manage-azdo-docs&utm_medium=changelog&utm_campaign=ignite-nov-2026).

### [Let Copilot work in your browser](#archive-heading-2)

Ask Copilot to fill out forms, pull information from webpages, or test and debug the web app you’re building, right in the browser you’re already signed in to. Browser use, now in public preview, works in Chromium-based browsers, including Google Chrome and Microsoft Edge, with the [GitHub Copilot extension for Chrome](https://chromewebstore.google.com/detail/github-copilot/hblomdgalaelcilcdepgohfcogjiijhe) and runs in an isolated tab group. It also works alongside computer use.

Browser use is off by default. To get started, install the extension, then open **Settings** > **Computer Use** and turn on both **Enable Computer Use** and **Enable Browser Use**. You can manage permission levels in the extension’s settings.

Browser use is also available in Copilot CLI, VS Code, and JetBrains IDEs.

For more information, see the [browser use documentation](https://gh.io/about-browser-use).

### [Bring your GitHub Enterprise Server work into the app](#archive-heading-3)

Add your GitHub Enterprise Server (GHES) account to work with remote repositories, issues, and pull requests in the GitHub Copilot app. GHES support, previously an opt-in preview, is now generally available. Update to GitHub Copilot app version 1.2.0 or later to use it.

To get started, sign in with a GitHub.com or GHE.com account, then open **Settings** > **Accounts** > **Add account** and choose **GitHub Enterprise Server**. Cloud sessions aren’t available for GHES.

For more information, see the [Copilot GHES documentation](https://docs.github.com/enterprise-server@latest/copilot/copilot-on-ghes/sign-in-on-copilot-app?utm_source=app-changelog-ghes-docs&utm_medium=changelog&utm_campaign=ignite-nov-2026).
