Repository plugin defaults and enterprise-managed plugin controls are now generally available in VS Code, Copilot CLI, and the GitHub Copilot app. Trusted repositories can install and enable default plugins for contributors. Enterprises can require plugins, block plugins, and restrict installation to approved marketplaces.

As a repository maintainer, you can define a plugin marketplace and default plugins so contributors don’t have to repeat setup for each project. Contributors can turn off repository defaults where policy permits.

As an enterprise administrator, you can supply approved marketplaces and require or block plugins through managed settings. Required plugins are automatically installed and enabled, and users can’t disable them. Managed settings take precedence over repository and personal choices.

Repository defaults are available to individual Copilot users and users with Copilot Business or Copilot Enterprise.

Managed controls are available on GitHub Enterprise Cloud for users with Copilot Business or Copilot Enterprise licenses issued by the enterprise or one of its organizations.

Learn more about [plugins for GitHub Copilot](https://docs.github.com/copilot/concepts/customizations/plugins).
