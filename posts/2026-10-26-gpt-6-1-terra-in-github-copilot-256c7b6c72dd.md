GPT-6.1 Terra, OpenAI’s newest model, is now generally available in GitHub Copilot. It is designed for everyday agentic coding and terminal work at a lower cost than GPT-6.1 Sol. In early testing, GPT-6.1 Terra solved noticeably more terminal and C# coding tasks than GPT-5.6 Terra. It works in focused, consolidated steps on well-scoped tasks.

This model is billed at provider list pricing under usage-based billing. See [Models and pricing for GitHub Copilot](https://docs.github.com/copilot/reference/copilot-billing/models-and-pricing) for details.

<a id="archive-heading-1"></a>

### [Availability in GitHub Copilot](#archive-heading-1)

GPT-6.1 Terra is available to Copilot Pro, Pro+, Max, Business, and Enterprise users. You can select the model in the model picker in:

-   Visual Studio Code
-   Visual Studio
-   Copilot CLI
-   GitHub Copilot cloud agent
-   GitHub Copilot app
-   github.com
-   GitHub Mobile on iOS and Android
-   JetBrains IDEs
-   Xcode
-   Eclipse

Rollout will be gradual. Check back soon if you don’t see it yet.

<a id="archive-heading-2"></a>

### [Enabling access](#archive-heading-2)

Copilot Enterprise and Copilot Business plan administrators can manage access to GPT-6.1 Terra through the model policy in Copilot settings. Under default model enablement, new models are automatically enabled unless an administrator has turned off the global default or explicitly disables this model.
