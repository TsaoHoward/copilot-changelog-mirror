You can now bring your work on GitHub Enterprise Server (GHES) into the GitHub Copilot app. Add your GHES account to work with remote repositories, issues, and pull requests. This feature was previously an opt-in preview, and is now generally available.

You’ll need to sign in with a GitHub.com or GHE.com account first. Then, go to **Settings** > **Accounts** > **Add account** and choose **GitHub Enterprise Server**.

Available in GitHub Copilot app 1.2.0 and later. Cloud sessions aren’t available for GHES. Learn more in our [Copilot GHES documentation](https://docs.github.com/enterprise-server@latest/copilot/copilot-on-ghes/sign-in-on-copilot-app).
