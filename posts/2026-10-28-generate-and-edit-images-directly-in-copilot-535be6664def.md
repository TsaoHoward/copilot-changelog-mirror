You can now generate and edit images using natural language in GitHub Copilot. When you ask for an image, your selected reasoning model calls a dedicated image-generation tool powered by GPT Image 2.5 Flare, previews the result inline, and saves it to your project.

Previously, getting a visual asset while working in Copilot meant stepping away to a separate tool, describing what you needed again, generating it there, and manually bringing it back into your project. This update removes that context switch, so you can go from an idea to a usable image without breaking your flow.

-   Describe an image conversationally in any Copilot chat session, whether you’re starting a new request or in the middle of a coding task.
-   Copilot previews the generated image inline and saves it directly to your workspace.
-   Organization and enterprise owners can turn off image generation by disabling the image generation model using [Copilot model policies](https://docs.github.com/copilot/concepts/enterprise/policies?utm_source=image-generation-changelog-policy-docs&utm_medium=changelog&utm_campaign=universe-2026).
-   You can opt in to a visible “Made with AI” watermark on images Copilot generates and edits. Watermarking is off by default.

To try it, open a Copilot chat in VS Code, the GitHub Copilot app, or Copilot CLI and describe the image you want.

Image generation is in public preview for Copilot Pro, Copilot Pro+, Copilot Business, and Copilot Enterprise. It’s billed separately from your chat model, based on image tokens that count toward your plan’s AI credits.
