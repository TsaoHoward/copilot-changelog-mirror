OpenAI’s GPT-6.2 Astra and GPT-6.2 Sol are now generally available in GitHub Copilot. Both models are designed for agentic coding and code review, with stronger coding judgment than earlier GPT-6 models. In early testing, both caught significantly more real issues in code review than earlier GPT-6 models while using fewer tokens.

-   **GPT-6.2 Astra:** OpenAI’s latest Astra model for agentic coding and terminal work. In early testing, it caught significantly more issues in code review than GPT-6 Astra and completed agentic coding tasks using noticeably fewer tokens.
-   **GPT-6.2 Sol:** OpenAI’s latest Sol model for complex agentic coding and in-depth code review. In early testing, it caught nearly twice as many real issues in code review as GPT-6.1 Sol while keeping its findings accurate.

These models are billed at provider list pricing under usage-based billing. See [Models and pricing for GitHub Copilot](https://docs.github.com/copilot/reference/copilot-billing/models-and-pricing) for details.

### [Availability in GitHub Copilot](#archive-heading-1)

GPT-6.2 Astra and GPT-6.2 Sol are available to Copilot Pro+, Max, Business, and Enterprise users.

You can select the models in the model picker in:

-   Visual Studio Code
-   Visual Studio
-   Copilot CLI
-   GitHub Copilot coding agent
-   GitHub Copilot app
-   github.com
-   GitHub Mobile on iOS and Android
-   JetBrains IDEs
-   Xcode
-   Eclipse

Rollout will be gradual. Check back soon if you don’t see the models yet.

<a id="archive-heading-2"></a>

### [Enabling access](#archive-heading-2)

Copilot Enterprise and Copilot Business plan administrators can manage access to GPT-6.2 models through the model policy in Copilot settings. Under default model enablement, new models are automatically enabled unless an administrator has turned off the global default or explicitly disables these models.
