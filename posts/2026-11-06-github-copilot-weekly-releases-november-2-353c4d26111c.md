This week, Copilot comes to JetBrains Air and Xcode’s coding assistant, with updates to help you manage pull requests, settings, and agent sessions.

<a id="archive-heading-1"></a>

### [GitHub Copilot app](#archive-heading-1)

-   Set up Agent Merge directly from a pull request to have Copilot merge it when it’s ready. It now stays enabled while required checks or rules are pending. You can also check reviewer status, request additional reviews, and select comment text to quote it or discuss it with Copilot.
-   Keep working when a conversation reaches its context limit. Compact the conversation or review what’s using the available space directly from the error.
-   Start a session by dropping files on “New” in the sidebar. CSV and TSV files now open as tables with sticky headers and an option to view the source.
-   Manage sessions in fewer steps. Archive pinned sessions whose pull requests have merged or closed, pin or unpin multiple sessions, and separate nested chats without losing the conversation. My Work now supports more than ten saved custom views.
-   Give Copilot guidance on which tool requests to approve without asking you. Personal instructions for assisted approval are opt-in and apply to local sessions.

Install the [GitHub Copilot app](https://gh.io/app).

<a id="archive-heading-2"></a>

### [GitHub Copilot CLI](#archive-heading-2)

Manage your whole setup in one place. `/settings` now opens a unified dashboard for your plugins, MCP servers, and more, and you can search across all of your settings.

<a id="archive-heading-3"></a>

### [GitHub Copilot in JetBrains](#archive-heading-3)

Introducing a new way to use GitHub Copilot in JetBrains IDEs, with Copilot now available in JetBrains Air. Track multiple agent sessions and run tasks locally in your JetBrains IDE or in the cloud through Air Teams, using your existing Copilot subscription.

Get started with [Copilot in JetBrains Air](https://github.blog/changelog/2026-11-03-github-copilot-is-now-available-in-jetbrains-air/).

<a id="archive-heading-4"></a>

### [GitHub Copilot in Xcode](#archive-heading-4)

You can now work with GitHub Copilot directly in Xcode’s built-in coding assistant, bringing Copilot into your native Xcode workflow. The integration is now in public preview, available starting with Xcode 27.3 beta.

Get started with [Copilot in Xcode](https://github.blog/changelog/2026-11-04-github-copilot-is-now-available-in-xcodes-coding-assistant/).

<a id="archive-heading-5"></a>

### [GitHub Copilot in VS Code (1.145 release)](#archive-heading-5)

-   Follow the conversation without the clutter or, alternatively, choose to inspect every step. Experimental chat view modes let you collapse or expand reasoning and tool calls without starting a new conversation.

<video loop="" controls="" autoplay="" muted="" width="100%" aria-label="VS Code Conversation, Verbose, and Compact chat views side by side" src="https://github.com/user-attachments/assets/5c8d704b-a308-49d1-9613-e1f2edecc7e7"><br></video>

-   Check an agent’s work on another machine without leaving VS Code. Preview remote apps and use interactive canvases in the Agents window, now in preview. Enable remote browser support in settings, plus canvases to use that feature.  
    ![Browser conected to a remote host](https://github.com/user-attachments/assets/383a4f6c-9d55-4282-b586-006e9e02b985)
-   Run recurring tasks on a schedule that fits your workflow. Local automations now support cron expressions and custom agents from your workspace.  
    ![cron job running in vs code](https://github.com/user-attachments/assets/20e33f0a-b958-4553-89dc-bd956937fef9)
-   Bring screenshots, mockups, and other files into chat without moving them into your workspace. Choose them with **Add Context** > **Files**. Cloud sessions only support images.
-   Get back into long Copilot chats more smoothly. Past terminal output now renders as you expand or reveal it instead of loading all at once.

Explore everything that’s new in the [full release notes](https://code.visualstudio.com/updates/v1_145).
