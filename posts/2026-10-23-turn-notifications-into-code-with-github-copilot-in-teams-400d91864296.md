The new GitHub app in Teams brings notifications and Copilot together, helping teams turn issues into fixes and ship code faster without leaving the conversation.

Get notified in channels, group chats, or private chats, then @mention GitHub to turn updates into action.

## [Get started](#archive-heading-2)

Explore the new [GitHub app in Microsoft Teams](https://teams.microsoft.com/l/app/ca9e26b7-dce5-44a0-b2b7-a70a3d65ce25), previously called GitHub notifications. If you already have GitHub notifications installed, update the app to the latest version. Your existing notification capabilities will continue to work.

If you use the legacy GitHub app, which will be renamed “GitHub (deprecated)” and retired on November 16, install the consolidated GitHub app using the link above to continue using Copilot in Teams. In the consolidated app, mention `@GitHub` and follow any prompts to connect your GitHub account and select a repository.
