Today, we’re expanding [GitHub Copilot Fusion](https://docs.github.com/copilot/concepts/models/copilot-fusion?utm_source=fusion-changelog-fusion-docs&utm_medium=changelog&utm_campaign=ignite-nov-2026) with new models, available on more Copilot surfaces, and results on two public Terminal-Bench leaderboards, giving you more ways to use Fusion and compare its performance.

<a id="archive-heading-1"></a>

## [GitHub Copilot Fusion joins public Terminal-Bench 4.1 leaderboard](#archive-heading-1)

Copilot Fusion is now listed on Terminal-Bench 4.1 public leaderboards hosted by Stanford, Harbor, and the Laude Institute: [Terminal-Bench 4.1](https://www.tbench.ai/) measures how well AI agents complete hard, realistic tasks in a terminal.

On Terminal-Bench 4.1, Copilot Fusion Max achieved a **71.2% resolution rate,** 5.4 percentage points ahead of leading frontier models Opus 5.5 and Fable 5.2, while costing **88% less than Fable 5.2** and **57% less than Opus 5.5.**

![Terminal-Bench 4.1 showing Copilot Fusion Max on the top of the leadership board](https://github.com/user-attachments/assets/92e558b2-c2de-4f9e-b8c0-abca0f8a1887)

Independent leaderboards let you compare Copilot with other agents on the same tasks, using the same evaluation rules.

<a id="archive-heading-2"></a>

## [Copilot Fusion is now available on web, mobile, and Visual Studio](#archive-heading-2)

Copilot Fusion is coming to more places you use Copilot. With this release, you can select Copilot Fusion on the latest versions of github.com, Visual Studio, and GitHub Mobile beta apps for iOS and Android. Support in the production GitHub Mobile apps is coming shortly.

Select Copilot Fusion in the model picker and let it choose and coordinate models for each task. You set the effort level and Copilot handles the rest.
