You can now work with GitHub Copilot directly in [Xcode’s built-in coding assistant](https://developer.apple.com/xcode/), bringing Copilot into your native Xcode workflow. The integration is now in public preview, available starting with Xcode 27.3 beta.

This gives you another way to use Copilot in Xcode. The existing GitHub Copilot for Xcode extension remains a separate option, so you can choose the workflow that works best for you.

<a id="archive-heading-1"></a>

## [Get started](#archive-heading-1)

Download Xcode 27.3 beta from [Apple Developer Downloads](https://developer.apple.com/download/). You’ll need a Mac running macOS Tahoe 26.6 or later.

In Xcode, open **Xcode > Settings > Intelligence** to set up GitHub Copilot in the coding assistant. For more information, see [Setting up coding intelligence](https://developer.apple.com/documentation/xcode/setting-up-coding-intelligence) and the [Xcode 27.3 beta release notes](https://developer.apple.com/documentation/xcode-release-notes/xcode-27_3-release-notes). All Copilot plans are supported.
