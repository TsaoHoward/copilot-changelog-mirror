As of today, November 16, 2026, we have deprecated the following models across most GitHub Copilot experiences (including Copilot Chat, inline edits, ask and agent modes, and code completions). Note that Claude Opus 4.8 is still available to individual GitHub Copilot subscribers on annual plans.

These deprecations were [announced on October 15, 2026](https://github.blog/changelog/2026-10-15-upcoming-deprecation-of-selected-github-copilot-models-in-mid-november/).

| Model | Deprecation date | Suggested alternative |
| --- | --- | --- |
| Claude Opus 4.8 | 2026-11-16 | Claude Opus 5.5 |
| Claude Opus 5 | 2026-11-16 | Claude Opus 5.5 |
| GPT-5.6 Terra | 2026-11-16 | GPT-6.1 Sol or GPT-6 Luna |

Claude Opus 5 has been removed from the model picker but remains available for runtime refusal fallback through existing authorized access. Existing enterprise model policies continue to apply.

Please update your workflows and integrations to use supported models. Under default model enablement, the suggested alternatives are automatically enabled for Copilot Enterprise and Copilot Business customers unless an administrator has turned off the global default or explicitly disabled the model. If you’ve turned off the global default, you can enable access to the alternative models through their model policies in Copilot settings.

Once enabled, users will see the model in the Copilot Chat model selector in supported GitHub Copilot experiences. No action is required to remove the deprecated models.

GitHub Enterprise customers with questions or concerns are encouraged to reach out to their account manager for further assistance.
